# 多人版部署上线指南

本文串联「后端（Supabase）」与「前端（PWA）」的部署步骤。后端细节见 `supabase/README.md`。

## 登录方式

**手机号 + 密码**：注册填手机号+密码，登录用手机号+密码。0 成本、无短信资质要求（Supabase Auth 托管密码存储）。

## 一、后端部署

### 1. 创建 Supabase 项目
1. https://supabase.com → GitHub 登录 → **New project**
2. Name 如 `dialysis`、数据库密码记好、Region 选 `Southeast Asia (Singapore)`

### 2. 建表 + 权限
- **SQL Editor** → 粘贴 `supabase/schema.sql` 全部内容 → Run

### 3. 部署 Edge Functions
```bash
# 安装 CLI 并登录
npm install -g supabase
supabase login
supabase link --project-ref <项目引用ID>

# 部署三个函数
supabase functions deploy register
supabase functions deploy create-patient
supabase functions deploy invite-member
```
（Windows 也可直接跑 `supabase/deploy-functions.ps1` 交互式执行）

### 4. 获取前端连接信息
**Project Settings → API**：记下 **Project URL** 与 **anon public key**。

## 二、前端部署

### 1. 配置环境变量
复制 `.env.example` 为 `.env`，填入上一步的两个值：
```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### 2. 构建
```bash
npm install
npm run build     # 产物在 dist/
```

### 3. 部署到免费静态托管
把 `dist/` 上传到：Cloudflare Pages / Vercel / Netlify / Gitee Pages（免费，HTTPS 必须）。

### 4. APK（可选）
按 `README.md` 的 Capacitor 流程重打包；`@capacitor/preferences` 负责 APK 内持久登录。

## 三、上线验证

1. 手机打开前端 → 登录页 → **注册**（手机号 + 密码）→ 自动登录
2. 「设置 → 我的病人」→ 「＋ 新建」建病人
3. 「设置 → 上传本地数据到云端」迁移本地数据（可选）
4. 「成员管理」→ 邀请家属手机号（对方需先注册登录一次）→ 设置角色
5. 多端登录：家属手机上也能看到该病人，共同记录、查看报告

## 四、成本

- Supabase 免费层：500MB 数据库 / 5 万月活，家庭/小团队完全够用。
