# 多人版部署上线指南

本文串联「后端（Supabase + 腾讯云短信）」与「前端（PWA）」的部署步骤。后端细节见 `supabase/README.md`。

## 一、后端部署

### 1. 创建 Supabase 项目
1. https://supabase.com → GitHub 登录 → **New project**
2. Name 如 `dialysis`、数据库密码记好、Region 选 `Southeast Asia (Singapore)`
3. 等待创建完成

### 2. 建表 + 权限
- **SQL Editor** → 粘贴 `supabase/schema.sql` 全部内容 → Run

### 3. 配置腾讯云短信（需实名）
1. https://console.cloud.tencent.com/smsv2 → 实名认证（个人）
2. 创建应用 → 得到 **SmsSdkAppId**
3. 申请**签名**（如「透析记录」）与**模板**（"您的验证码为{1}，5分钟内有效"），审核 1~2 天
4. CAM 拿到 **SecretId / SecretKey**（建议子账号仅授 `sms:SendSms`）

### 4. 部署 Edge Functions + 配置密钥
```bash
supabase login
supabase link --project-ref <项目引用ID>
supabase functions deploy send-otp
supabase functions deploy verify-otp
supabase functions deploy create-patient
supabase functions deploy invite-member

supabase secrets set TENCENT_SECRET_ID=xxxx TENCENT_SECRET_KEY=xxxx
supabase secrets set TENCENT_SMS_APP_ID=1400xxxxxx
supabase secrets set TENCENT_SMS_SIGN=透析记录
supabase secrets set TENCENT_SMS_TEMPLATE_ID=1234567
supabase secrets set TENCENT_SMS_REGION=ap-guangzhou
```

### 5. 获取前端连接信息
**Project Settings → API**：记下 **Project URL** 与 **anon public key**。

## 二、前端部署

### 1. 配置环境变量
复制 `.env.example` 为 `.env`，填入上一步的两个值：
```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### 2. 构建
```bash
npm install
npm run build     # 产物在 dist/
```

### 3. 部署到免费静态托管
把 `dist/` 上传到：Cloudflare Pages / Vercel / Netlify / Gitee Pages（免费，HTTPS 必须）。

> 若配置了 `.env`，构建时 Vite 会把密钥打进产物——**anon key 是公开的**，配合 RLS 使用是安全的；真正敏感的是服务端密钥（只存在 Edge Function 里）。

### 4. APK（可选）
按 `README.md` 的 Capacitor 流程重打包；`@capacitor/preferences` 负责 APK 内持久登录。

## 三、上线验证

1. 手机打开前端 → 出现登录页 → 输入手机号 → 收到验证码 → 登录成功
2. 「设置 → 我的病人」→ 「＋ 新建」建病人
3. 「设置 → 上传本地数据到云端」迁移本地数据（可选）
4. 「成员管理」→ 邀请家属手机号（对方需先注册登录一次）→ 设置角色
5. 多端登录：家属手机上也能看到该病人，共同记录、查看报告

## 四、成本

- Supabase 免费层：500MB 数据库 / 5 万月活；
- 腾讯云短信：约 ¥0.05/条（家庭小规模每月几毛到几元）。
